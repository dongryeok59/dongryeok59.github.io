## 글자 고치기 (누구나)

화면에 나오는 글은 전부 **`content/pledges.json`** 한 파일에 있습니다.

1. 이 저장소에서 `content` → `pledges.json`을 엽니다.
2. 오른쪽 위 연필 아이콘(Edit this file)을 누릅니다.
3. `Ctrl+F`(맥은 `Cmd+F`)로 고칠 문장을 찾아서, **따옴표 `" "` 안의 글자만** 바꿉니다.
4. 오른쪽 위 **Commit changes** → 한 번 더 **Commit changes**.
5. 1~2분 뒤 사이트에 반영됩니다. 상단 **Actions** 탭에서 초록 체크가 뜨면 끝입니다.

### 어디가 어디인지

| 화면 | 파일에서 찾을 이름 |
|---|---|
| 맨 위 표지 제목·문구 | `bookTitle`, `sloganSub` |
| 기조문 | `statement` (`intro`, `powers`, `outro`) |
| 출마소견 | `speech` |
| 후보 이력 | `candidates` → `history` |
| 투표 기간·시간·방법 | `vote` (`start`·`end` 날짜는 D-day 계산에 쓰이니 기간을 바꾸면 같이 바꿉니다) |
| 공약 제목 / 한 줄 약속 | 각 공약의 `title` / `promise` |
| 공약 찾기(검색) | 따로 고칠 것 없음. 공약의 `title`·`promise`에서 자동으로 찾습니다 |
| 왜 필요한가요 / 어떻게 추진하나요 | `why` / `how` |
| 도식(단계 흐름) | `blocks` → `steps` |
| 월별 추진 일정 | `roadmap` → `rows` (`facility` 시설, `academic` 배움, `connect` 모두) |

### 지켜야 할 것

- `"id"`, `"core"`, `"type"` 같은 **영어 이름과 값은 건드리지 않습니다.** 바꾸면 링크가 끊깁니다.
- 따옴표 `"`, 쉼표 `,`, 괄호 `[ ] { }`를 지우지 않습니다. 문장 안에 큰따옴표가 필요하면 ‘ ’ 나 “ ”를 씁니다.
- 월별 일정의 `[계절학기 수요조사](summer-session)`는 **굵은 글씨 링크**입니다. `[ ]` 안 글자만 바꾸고 `( )` 안은 그대로 둡니다.
- 실수로 형식이 깨지면 Actions 탭에 빨간 X가 뜨고, **사이트는 이전 상태 그대로 유지**됩니다. 고쳐서 다시 저장하면 됩니다.
- 학번 전체, 연락처, 이메일, 서명·도장, 확정 안 된 예산·일정은 넣지 않습니다.

## 위치·크기·색 바꾸기

배치와 디자인은 `site/src/App.tsx`, `site/src/index.css` 코드에 있습니다.
피그마와 연결돼 있지 않아서 피그마를 고쳐도 사이트는 바뀌지 않습니다.
화면 캡처에 바꿀 곳을 표시해서 Claude에게 맡기는 게 가장 빠릅니다.
